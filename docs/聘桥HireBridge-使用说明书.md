# 聘桥 HireBridge · 使用说明书

> 面向日常使用同事。按实际界面和按钮编写，照着做即可上手。
> 适用版本：2026-11-19 线上版。若你的界面与文中不符，按 `Ctrl + F5` 强制刷新后再看。

---

## 写在前面

聘桥是一套给招聘团队用的工作台，把「上架岗位 → 收集简历 → AI 评估 → 发测评问卷 → 跟进面试 → 入职归档」这一整条流程放在同一个地方。

**访问方式**：打开团队分享的链接，用 WorkBuddy 账号扫码登录。首次登录建议先到「用户中心」把昵称改成自己的名字——之后你录入的每位候选人，都会显示这个「录入人」名字。

---

## 一、先弄懂四件事

### 1. 数据只看自己的

每位同事登录后，只能看到、修改自己录入的岗位和候选人，互相不串数据。这既是系统设计，也是数据库的权限规则（行级隔离）。需要把信息给对方时，靠的是发问卷链接或导出台账文件，而不是让对方登录你的账号。

### 2. 综合分怎么来的

候选人的「综合分」满分 100，由两部分各占一半：

- **AI 评估分（50%）**：系统按你为该岗位设定的 JD 评分维度，逐条对照简历生成，附证据；
- **问卷评估分（50%）**：候选人填写专属测评问卷后，由系统按题目权重计算。

只完成其中一项时，综合分显示「待补全」，不会拿一半冒充满分。**系统不设及格线、不自动淘汰任何人**，分数只用于人工排序。招聘原因和市场类型只作业务记录，不参与打分。

### 3. 问卷是一人一码

每个岗位绑定一份测评问卷后，系统为每位候选人生成专属链接。候选人打开链接、填写与档案一致的姓名和手机号即可作答，**无需扫码登录**；同一人的链接重复提交会被拦截，不会重复计分。候选人提交后只看到感谢页，看不到分数。

### 4. 招聘阶段只能一格一格走

管道里只有四列：简历筛选 → 面试中 → Offer → 已入职。推进或回撤每次只移动一格，不能跳步。每次阶段变动都会留下审计记录。

## 二、快速开始：5 步跑通一个岗位

### 第 1 步：上架岗位

进入左侧「上架岗位」，点右上角「上架新岗位」，按三个标签页填写：

1. **JD 与评分规则**：上传 JD 文件（PDF / DOC / DOCX / TXT / MD / CSV / Excel）或直接粘贴 JD 原文，点「按 JD 生成评分维度」。系统会给出若干维度和权重，权重合计须为 100%。请逐条核对、必要时修改并勾选确认——这一步决定 AI 用什么标准给简历打分。
2. **基础信息**：填公司名称、岗位名称、部门、地点、用工类型、招聘人数、薪资预算等。
3. **招聘原因与市场**：多选招聘原因、选择市场类型（人的市场 / 岗位的市场）。这部分**只记录、不打分**。市场分由系统在后台固定（人的市场 7 分、岗位的市场 3 分），界面不显示，也不需要你填。

> 提示：问卷不在这里绑定。保存岗位后，到「测评问卷」里再绑。

### 第 2 步：建问卷并绑定到岗位

进入「测评问卷」，点「新建问卷」：

1. 填标题、添加题目。支持四种题型：单选、多选、量表 1–5、开放题；每题可设权重。
2. 问卷末尾会自动附带一组**档案题**，共 8 道，必填、不能删除、不计分：身份证号码、职业规划/初步意向、当前机会/离职原因、可以接受的区域、有意向的工作城市、期望薪资、预计入职时间、是否同意被系统留档。候选人填完后，这些会自动回填到台账对应字段。
3. 在问卷卡片的「绑定岗位」下拉里选中刚建的岗位。一个岗位同时刻只有一份生效问卷；修改问卷会生成新版本，旧答卷保留。

### 第 3 步：导入简历

三种方式按需选择：

- **单份录入（AI 评估简历）**：上传简历，选岗位，确认识别出的姓名、手机号等，系统按 JD 生成带证据的分析并入库。适合重点候选人。
- **批量简历导入**：顶部先选「默认岗位」，再点「选择简历」，可一次选多份（PDF / DOC / DOCX / TXT / Excel），最多 4 份并行解析。每份卡片可手改识别出的字段、绑定岗位，互不影响。入库后自动生成并绑定该候选人的专属问卷。
- **资料导入**：按姓名和目录结构把本地简历原件批量挂到**已有**候选人档案里，不新增候选人。用于补齐历史文件。

> 识别准确度：姓名、电话、邮箱、城市等按简历原文确定性提取；院校、专业、技能等由模型补全。识别有误不用急，在候选人详情里可直接改。招聘平台导出的手机号常被掩码（如 `158****3920`），这类号码一律留空，等候选人填问卷时补回。旧 DOC 是尽力而为的启发式提取，建议尽量用 DOCX。

### 第 4 步：把问卷发给候选人

- **单个发送**：在「人员管理」或「候选人管道」里点开候选人，详情中有「专属测评链接」，点复制发给本人；链接页也带二维码。
- **按岗位导出二维码**：在「测评问卷」里可按岗位导出 Excel，含姓名 / 岗位 / 链接 / 二维码图片，方便群发。

候选人打开链接 → 填姓名 + 手机号核对身份 → 作答 → 提交。若需重填，在候选人详情点「刷新问卷」，会清除原答卷和得分、链接恢复可填（有二次确认，评分历史保留）。

### 第 5 步：跟进、推进与导出

- **人员管理**：按岗位、问卷状态等筛选，按综合分/建档日期等排序。顶部「导出台账」**只导出你勾选的人**，并按项目拆分 sheet，每个项目用各自的问卷列。
- **候选人管道**：点「推进」按钮或拖拽进入下一阶段，也可「回撤」逐格退回。**进入「面试中」的卡片不再显示技能标签，而是直接展示面试信息**：是否接受、是否参面、时间、形式、结果；选了「拒绝」会标红。点卡片上的「编辑」即可登记或修改。
- **面试安排**：一张面试记录表，按人列出一面 / 二面。点任意轮次登记接受、参面、时间、形式、结果与备注；行末「删除」可清空该人全部面试记录，轮次格内的小垃圾桶只删该轮。台账导出会把这些字段按一面 / 二面分列。
- **数据漏斗**：看各环节人数与转化。历史数据不完整时会标注「跳步」，不补造记录。

## 四、常用操作详解

### 修改候选人信息

任意列表点开候选人 → 切到「候选人资料」页签，可直接改姓名、电话、邮箱、城市，以及简历提取和问卷回填的各类台账字段，保存后立即生效。注意：若候选人重新提交问卷，问卷里填的内容会覆盖对应字段——以问卷为准的字段请谨慎手改。

### 改岗位

- 人员管理列表的「岗位」列是下拉框，直接选即可改。
- 候选人卡片详情底部有「修改和绑定岗位」。改岗位后，旧岗位的测评链接会作废，系统按新岗位问卷重新生成一人一码；已提交的旧答卷保留。

### 导出台账

在「人员管理」**先勾选要导出的人**，再点「导出台账」。没勾选会提示先勾选。导出规则：

- 勾选的人按项目分组；只有一个项目时导出单 sheet，多个项目时**每个项目一个 sheet**；
- 每个 sheet 用该项目自己的问卷题生成「问卷·题目」列，不会串列；
- 含一面 / 二面的接受、参面、时间、形式、结果及面试备注；
- AI 评估相关列标注「仅供参考」，请结合证据人工判断。

### 管理员能做什么

在数据库中获授权的管理员可通过「用户中心」进入管理员模式。开启后可只读查看其他账号的数据。访问范围由数据库规则决定。管理员还能在「用户中心 → 存储清理」扫描并清理已被删除候选人遗留的孤儿简历文件。

## 五、常见问题

**Q：为什么我只能看到自己录入的人？**
A：系统按账号隔离数据，每人只看自己的，这是设计如此。需要协作请发链接或导出文件给对方。

**Q：手机号为什么是空的？**
A：招聘平台导出的简历里手机号常被掩码，这类号码不会被写入台账。候选人提交专属问卷时填的完整手机号会自动回填。

**Q：姓名或字段识别错了怎么办？**
A：在候选人详情的「候选人资料」里直接改。旧的已入库记录不会自动重跑识别，需要人工改；新导入的简历用新版识别规则。

**Q：导入后没看到问卷绑定？**
A：最新版在简历入库时就会自动生成并绑定问卷。若岗位本身没绑问卷，会提示「岗位未绑定问卷」，先去「测评问卷」绑定即可。

**Q：综合分一直显示「待补全」？**
A：说明 AI 评估和问卷评估只完成了一项，两项都完成后才会显示完整综合分。

**Q：候选人提交问卷后能看到分数吗？**
A：不能。候选人端只显示感谢页，分数只在工作台里给招聘同事看。

**Q：页面数据不是最新的？**
A：工作台会自动同步远端变化。若界面停留在旧样式，按 `Ctrl + F5` 强制刷新浏览器缓存。

## 六、一页速查（SOP）

1. 用户中心改昵称
2. 上架岗位（JD + 评分维度 + 岗位信息 + 招聘原因）
3. 测评问卷（出题 + 权重 + 绑定岗位）
4. 导入简历（单份 / 批量 / 原件）
5. 复制专属问卷链接发给候选人
6. 候选人填问卷、手机号回填
7. 人员管理看综合分、勾选导出台账
8. 管道推进 / 回撤、在面试安排里登记一面二面
9. 数据漏斗看转化
10. 入职后在云聘集成里建档（可选）
